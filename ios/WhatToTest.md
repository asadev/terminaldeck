What to test — 0.10.0

Your last build was 0.9.0. This one is mostly about the phone catching up to the
desktop: five things the Mac and Windows apps could already do now work from
iOS. Open each on the phone against a machine you have paired with.

Sign in. The pairing screen now takes a full sign-in link, not only a code.
Paste the link a machine hands you and the phone enrolls itself the same way the
browser client does — no code to retype.

Devices. There is a Devices screen listing every phone, browser and desktop that
has signed in to a machine. This phone is marked as such. Removing a row takes
that device's access away immediately.

Server settings. A machine now exposes its own settings to the phone: the
default coding tool it starts sessions with, and whether it restores sessions at
launch. These belong to the machine, not the phone — change one here and every
device that reaches that machine sees the new value.

Controls. A session with an agent can have its model, effort and permission mode
set from the phone. Open a session, open Controls, and switch the model — the
change lands on the machine running it.

Watch the browser. When a machine has a browser window open, or a session has
one attached, it shows up under Watch browser. Open a surface and it streams to
the phone full screen; type into it and the keystrokes drive the real browser on
the machine.

Version awareness. The About row reads 0.10.0, and the app now knows when the
machine it is talking to is on an older or newer build than itself.

Everything else is desktop-side and carried over from the 0.9.0 review.
