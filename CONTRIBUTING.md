# Contributing

Fork this repository, make a branch, and open a pull request against `main`.
Windows code lives under `windows/`; Mac code lives under `macos/`, with shared
web code in `src/` and `pwa/`. Include what changed and how you checked it.

Pull requests are welcome. The maintainer reviews and picks what ships; not every pull request is merged. Merged work ships with the next release, credited to its author.

All apps use one version number; release maintainers handle version changes.
The Mac and Windows code is MIT-licensed: keep the copyright and permission
notice. Please also credit Terminal Deck when building on it;
that credit request is a note, not an extra licence condition. See `LICENSE`
and `NOTICE`.
