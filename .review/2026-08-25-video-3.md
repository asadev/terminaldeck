app. **That was wrong, and he corrected it.** Verified by walking the process tree

```

 |- unshare --user --map-root-user ... -> claude      pts/8
 |- unshare --user --map-root-user ... -> claude      pts/9
```

That is the **headless host**, running as `asad`, with our own Linux confinement

was driving. The Windows app's sessions (`pts/2`, `pts/3`, `pts/7`, spawned through

His instruction: *"we are not focusing on PC application right now, we are working on
headless Terminal Deck... the one headless in the server is not something which is
being used for anything, which is all about test — all of your tests, all of my

So the headless host is the test target and may be redeployed and restarted freely.
The Windows install is not to be touched.

**Version numbers cannot tell these apart.** His Menu screen reads `Terminal Deck

why he is still seeing markdown, and redeploying the headless host is the fix.
