## Preserved rules and disk formats

- Memory: 2,000 notes; depth 4; 256 KiB read/save cap; exact modification time plus byte count for save; no note creation; canonical path and symlink escape refusals; real Trash; optional exact MEMORY.md index lines; provenance newest 60 conversations, 8-second budget, 512-line deadline checks, latest 50 writes. Uses existing `BackendArtifactsIndex.touches`, not a second touch parser.
- File events: lazy native FSEvents per opened space, no polling; add/change/delete updates notes, graph and BM25; 150 ms changed-event debounce. Dropped/must-scan/root-changed/ID-wrap events reconcile the full bounded index; absent roots remove stale entries. Watch startup errors are reported.
- Search: Unicode letter/number terms, BM25 k1 1.2/b 0.75, title weight 3, last-word prefix, source snippet bounds; tool note output cap 64 Ki UTF-16 units, search default 10/max40 and IPC max40.
- Knowledge: `knowledge/<first16 SHA256(real project)>/project.json`, `<id>.md`, flat front matter in the original 16-key order, comma-separated evidence, ISO millisecond timestamps, optional stale-after-days; `log.jsonl` keeps whole deleted files and reasons; `knowledge/shares.json` stores `{shares:[{from,to,at}]}`. Corrupt shares fail closed. Replacement is written before retiring old record. Public writes are claims; only task review events with named evidence become verified. Status derives from same-project disagreements and evidence mtimes; results age 30 days, architecture 90, standing rules have no default expiry.
- Briefs: max4,000 UTF-16 units, default12/max40 search hits, max8 own standing rules, max5 same-goal records, trust ranking, four source section labels, provenance tails and omitted-record count. Task storage/brief errors report and let task flow continue, matching index.ts's explicit fallback.
