## Real wire surface

| Channel | Args | Return |
| --- | --- | --- |
| `browser-download:list` | none | `DownloadsView` |
| `browser-download:destination` | destination object | `DownloadsView` |
| `browser-download:cancel` | download ID | `DownloadsView` |
| `browser-download:clear` | none | `DownloadsView`; finished rows removed, files retained |
| `browser-download:open` | download ID | `{ ok, message }` |
| `browser-download:reveal` | download ID | `{ ok, message }` |
| `browser-download:folder` | none | path or empty string for cancelled chooser |
| `browser:downloads` | pushed event | one `DownloadsView` argument, scoped to the authenticated owner |

`BackendBrowserDownloadsRPC.registerChannels(in:ownerID:)` registers all seven and rolls back this factory's registrations if a registration fails. `forwardEvents(to:context:)` returns a `Task<Void, Error>` that the runtime must retain and cancel on disconnect. It recomputes permissions for each update and publishes with `ownerID`; do not replace it with a global publish. Per-consumer buffered overflow ends the stream with an explicit reconnect/read-state error.

MCP factory: `registerMCP(in:resolveCaller:)`. Identity `browser.downloads`; wire `browser_downloads`; actions `list`, `cancel`, `clear`, `open`, `reveal`, `destination`. Default `list`, real object schema, extra arguments rejected, ordinary session caller refused, unattended chooser refused, usable failure messages returned through MCP replies. The resolver must supply `BackendBrowserDownloadsToolCaller(context:attended:isSession:)` from the **live authenticated** caller table. None of these are accepted from tool arguments.

## Exact integration edits for the exclusive worker

1. Construct one `BackendBrowserDownloads(dataRoot:defaultFolder:applicationName:dependencies:)` from the actual app-owned root, the source product default (`Downloads/<brand name>`), and the shared brand. Do not derive production paths inside this service. Pass `NativeSafariDownloadsSystem.dependencies(authorize:parentWindow:deliver:)`, or equivalent genuine AppKit/transport closures. Constructors are inert. Call `restore(context:)` explicitly before the first tab; the facade's explicit `start()` does this once and opens its event stream.
2. Bind the required async authorization callback to the shared `BackendBrowserAuthorization`. Its input is `(NativeRPCContext, BackendBrowserDownloadsAccess)`. Check the current tab/profile/session/origin and folder/device grants using `access.binding`, `access.row`, and `access.destination`. Old rows with no binding are local-app history and must not become visible to a remote/page/session caller by default. `.list` also covers private destination/default folder state; `.inspect` independently gates each row. `.start`, `.receive`, redirects, and `.deliver` must recheck runtime grants. `.receive` is a continuing transport grant check, not a new consent prompt on every progress event.
3. The callback must enforce the **effective** tier. `open` uses `.act` only for the source's recognized data formats with no executable bits; unknown files/installers/scripts/macros/executables escalate to `.alter`. `clear`, `destination`, chooser and remote delivery require `.alter`. The MCP server's registered base `.read` tier does **not** substitute for this callback's current consent/tier/action-log check. Use the real MCP caller's session registration to resolve current grants; `BackendMCPCallContext` alone does not carry allowed tiers or caller kind.
4. Supply remote delivery only from the remote transport owner's verified implementation. `BackendBrowserDownloadDelivery` contains the snapshotted destination, binding, digest, cancellation, source URL for display, and `openSource()` returning the actual retained inode as a `FileHandle`. The transport must read `openSource()`, honor cancellation and current device/folder grants, and return `.delivered(path:)` only after actual receiver placement. The only local removal occurs after that acknowledgement and a second grant check. No delivery implementation means destination-to-machine throws an explicit unavailable error; restore of an old remote destination cannot silently pretend to deliver.
5. Make `NativeBrowserTabs.downloads` an injected `NativeSafariDownloads` instance instead of `NativeBrowserDownloads()`. Supply a `resolveBinding` closure that maps the **actual WKWebView identity** through the live normal/isolated tab registry to a trusted `NativeRPCContext` and `BackendBrowserDownloadBinding(tabID:profileID:sessionID:machineID:origin:)`. Never build that binding from remote arguments or a guessed/default profile. The origin is the real tab's origin; the redirect callback supplies the proposed URL separately in `access.row.url`.
6. Change **both** `NativeBrowserTab.swift` navigation delegate callbacks near the current lines 817 and 821 from `downloads.adopt(download)` to `downloads.adopt(download, webView: webView)`. All normal and isolated WKWebViews must use the same adoption path. The new delegate never substitutes URLSession for authenticated WebKit responses and never reads cookies or credentials itself.

Keep `NativeBrowserDownloads.Item` as the pure presentation type; the new facade exposes the same `items`, `badge`, `runningCount`, `overallFraction`, `cancel`, `open`, `reveal`, `clearFinished`, `openDownloadsFolder` API. ## Behavior and deliberate limits

- Names use the source sanitization and numbered variants; the last fallback checks a UUID collision instead of blindly trusting a timestamp. The final filename is reserved for this run. WebKit writes `payload` in a new mode-0700 staging directory inside the selected local destination, so final publication stays on the same filesystem. `renameatx_np(..., RENAME_EXCL)` atomically refuses an existing file; a collision gets a new free name. No payload rewrite/copy or overwrite fallback exists. Unsupported exclusive rename/folder failures keep a truthful failed row and the staged payload for recovery.
- Every path component is opened with `O_DIRECTORY | O_NOFOLLOW`; final payload/read operations use `O_NOFOLLOW` and regular-file/inode checks. Folder symlinks are refused rather than followed. Supply actual canonical root paths for an intentional `/tmp`→`/private/tmp` alias or user-chosen folder alias; do not turn this into a grant bypass.
- Quarantine is written before final publication. A quarantine failure produces a failed row and removes the unmarked staging payload. A successful final save posts the existing Dock download-complete notification. The adapter does not read Keychain, auth databases, production stores or any other browser's data.
- Transport capability tickets contain a private nonce and are never exposed in a wire row/event/tool result. Rows and destinations remain source compatible, with optional `binding` and `persistenceMessage` extensions. Final paths are published only when bytes are complete. Failure/cancellation history never silently disappears. Finished rows may be cleared without deleting files.
- Historical rows still moving at shutdown restore as failed. History I/O is bounded to 4 MiB and uses a mode-0600 exclusive temporary file plus descriptor-relative atomic rename. Errors are visible through `persistenceMessage`. History normally keeps 100 rows; live rows are not discarded if more than 100 downloads are concurrently active, so that rare transient list can exceed the history cap. No constructor starts I/O.
- Digests use a utility task and the actual saved inode. Local success is visible before its digest finishes; an empty digest means unknown. Remote delivery waits for the seal, retains the file on any failure, and never deletes a local file merely because a remote URL/path was guessed. A confirmed transfer whose local cleanup fails shows the retained-copy message.
- WebKit's public download API accepts a destination **URL**, not an already-open file descriptor. NSWorkspace likewise opens a URL. The service validates private staging/current inode before publication/OS handoff, but another process running as the same user can still race pathname replacement inside the interval after a public API takes the URL. Public APIs cannot promise descriptor-exclusive ownership of WebKit's internal writer or NSWorkspace's final open. No private API/Chrome helper workaround is added.
- WebKit resumeData is neither persisted nor reused across profiles. The original download tool has no resume action; resume support is not claimed. This lane does not expose server CDP internals, cache filesystem paths/byte totals, Chrome integration or extensions.
