# terminaldeck

**This package is a name reservation. It contains no code.**

It exists so that the npm name `terminaldeck` belongs to the people who build
Terminal Deck, and not to somebody impersonating them. Installing it does
nothing — there is no entry point, no command, and no dependency.

## What Terminal Deck actually is

A desktop app (Electron, macOS and Windows, currently alpha) for running AI
coding agents — Claude Code, Codex, Gemini — several at a time in one window,
with their status and cost visible at a glance.

It is a GUI application, not a Node library and not a CLI, so it is not
distributed through npm and this package will never become the app.

## Where to get it

- Website: <https://terminaldeck.dev>
- Source and releases: <https://github.com/asadev/terminaldeck>
- Download: <https://github.com/asadev/terminaldeck/releases>

Releases carry a macOS (Apple silicon) build and a Windows (x64) build. The
repository explains how to build from source.
